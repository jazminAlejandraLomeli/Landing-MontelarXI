Cómo editar el footer

El pie de página sale en todas las páginas. Sus columnas, enlaces, redes sociales y textos se leen de un solo archivo.

Archivo: src/data/footer.json
Aparece en: Todas las páginas · pie de página

Paso a paso

01

Abre el archivo

Abre src/data/footer.json. Las columnas están en "columns".

02

Agrega una columna

Copia un grupo completo y pégalo al final. El footer acomoda solo las columnas.

03

Agrega enlaces

Dentro de "links" cada renglón es un enlace: su texto y a dónde lleva.

04

Redes y textos

Las redes en "social" usan la misma forma. tagline, responsible y copyright son textos.

Así se agrega footer.json

Cada columna tiene un title y su lista de links. Para un solo enlace nuevo, agrega solo un renglón { "label": …, "href": … } dentro de links.

src/data/footer.jsonLo resaltado es lo nuevo
"columns": [
  { "title": "Ayuda", "links": [ … ] },
// ← tu nuevo grupo de enlaces: copia este bloque completo
  {
    "title": "Empresa",1
    "links": [
      { "label": "Nosotros", "href": "/nuestra-historia" },34
      { "label": "Escríbenos", "href": "mailto:tu-correo@ejemplo.com" },
      { "label": "Instagram", "href": "https://instagram.com/tu-cuenta" }
    ]2
  }
]

Qué va en cada campo

CampoQué esEjemplo / regla
1titleTítulo dorado de la columna.EmpresaObligatorio
2linksLista de enlaces de la columna, en el orden en que se ven.[ { … }, { … } ]Obligatorio
3labelTexto que se ve.NosotrosObligatorio
4hrefA dónde lleva el enlace./recetas una página · /#productos una sección · https://… otro sitio (abre pestaña nueva) · mailto: correo · tel: teléfonoObligatorio

Lo que pasa solo

  • La columna nueva aparece junto a las demás, en todas las páginas.
  • Los enlaces a otros sitios se abren en una pestaña nueva.
  • Los enlaces internos (/recetas) navegan sin recargar la página.
  • Las redes de "social" se ven bajo el logo; el año del © se actualiza solo.

Evita estos errores

  • Olvidar la coma entre el bloque anterior y el nuevo: }, antes de tu {.
  • Dejar una coma después del último campo o del último bloque.
  • Usar comillas tipográficas (“ ”) en lugar de comillas rectas (" ").
  • Dejar "href": "#": el enlace no lleva a ningún lado (está bien solo mientras tanto).
  • Escribir una red sin https:// al inicio.
